# வீடுகளுடன் பள்ளிகளும் {#more-than-houses-experimental}

Doorprints வீடு தேடுவதற்கான குறிப்பேடாகத் தொடங்கியது; இப்போது இணையதளத்திலும் தொலைபேசிகளிலும் இதே செயலி **பள்ளிகளையும்**
கண்காணிக்கிறது. நீங்கள் காட்டும்வரை பள்ளிகள் **முடக்கத்தில்** இருக்கும், எனவே Doorprints எப்போதும்போல உங்கள் வீடுகளிலேயே
திறக்கும். உண்மையான தொலைபேசிகளில் பள்ளிகளை நாங்கள் இன்னும் கையால் சோதிக்கவில்லை; ஏதாவது தவறாகத் தெரிந்தால் எங்களிடம் சொல்லுங்கள்.

**இயல்புநிலை** என்பது Doorprints கேட்க முடியாதபோது எடுத்துக்கொள்வது: Doorprints-இல்
நீங்கள் பகிரும் விளம்பரம், அல்லது புதிய பதிவைச் சேர்க்கும் இணைப்பு. நீங்கள் வேறொன்றைத் தேர்ந்தெடுக்கும்வரை வீடுகளே இயல்புநிலை.

## நீங்கள் எதைத் தேடுகிறீர்கள்? {#what-are-you-looking-for}

ஒன்றுக்கு மேல் காட்டப்படும்போது, Doorprints **நீங்கள் எதைத் தேடுகிறீர்கள்?** என்பதுடன் திறக்கும்: **வீடுகள்** என்ற ஒரு
அட்டை, **பள்ளிகள்** என்ற ஒரு அட்டை; ஒவ்வொன்றும் எத்தனை சேமிக்கப்பட்டன, கடைசியாக எப்போது மாறியது என்று சொல்லும். திறக்க
ஒரு அட்டையைத் தட்டவும். அங்கே எல்லாமே அந்த அட்டையுடையவை: பட்டியலும் வரைபடமும், பட்டியலுக்கு மேலே உள்ள எண்ணிக்கைகள்,
தேடல், **பள்ளியைச் சேர்** அல்லது **வீட்டைச் சேர்**, காலியான பட்டியலின் சொற்கள். முதல் முறை, இது எப்படி வேலை செய்கிறது
என்று ஒரு சிறு குறிப்பு சொல்லும்; **சரி** அதை மறைக்கும்.

மாற, மேலே நீங்கள் பார்ப்பதன் பெயருடன் உள்ள பொத்தானைப் பயன்படுத்தவும் (**பள்ளிகள் ▾**): அது உங்களை அட்டைகளுக்குத்
திருப்பிக் கொண்டுசெல்லும். பட்டியலிலிருந்து **பின்செல்** என்பதும் அப்படியே.

ஒன்று மட்டும் காட்டப்படும்போது தேர்ந்தெடுக்க எதுவும் இல்லை: Doorprints எப்போதும் போல நேராக அதிலேயே திறக்கும்.

தொலைபேசியில் இந்தப் பொத்தான் வரைபடம், பட்டியல், ஒப்பிடு, அமைப்புகள் ஆகியவற்றின் மேலே இருக்கும். **தேடல் பயன்முறை** ஒவ்வொரு பகுதியிலும் இயங்கும்: வரைபடத்தின் தேடல் அட்டை வீடுகளைப் பார்க்கும்போதும் பள்ளிகளைப் பார்க்கும்போதும் தெரியும்; அதன் அறிவிப்புகளும், இயங்கும்போது காட்டப்படும் அறிவிப்பும், வரிகளும் அதைத் தொடங்கிய பகுதிக்கு ஏற்ப *வீடு* அல்லது *பள்ளி* என்று சொல்லும் (வீடு 30 மீ-இலிருந்து, அல்லது அமைப்புகளில் நீங்கள் வைத்த தூரத்திலிருந்து அறிவிக்கும்; பள்ளி 100 மீ-இலிருந்து). *நீங்கள் ஒரு பள்ளியில் இருக்கிறீர்களா?* அறிவிப்பைத் தட்டினால் ஒரு பள்ளி உருவாகும். நடை நீங்கள் தொடங்கிய பகுதிக்குரியது: தேடல் பயன்முறை ஓடும்போது வேறு பகுதிக்குச் சென்றால் அது நின்றுவிடும், Doorprints ஒரு வரியில் சொல்லும்; வரைபடத்திலிருந்து மீண்டும் இயக்குங்கள். **அமைப்புகளில்** **தரகர்கள்**, **அளவுகோல்கள்** ஆகியவை வீடுகளுக்கானவை; நீங்கள் பள்ளிகளைப் பார்க்கும்போது அவை காட்டப்படாது; **கேள்விகள்**, **வீடு பார்வையிடல்** ஆகியவை பள்ளிகளுக்கும் காட்டப்படும், பள்ளியின் சொந்தச் சொற்களில். இணையதளத்தில் **உங்கள் தரவு** **அளவுகோல்கள்** அட்டைக்கு இதையே செய்கிறது; அதன் **கேள்விகள்**, **வீடு பார்வையிடல்** அட்டைகள் நீங்கள் பார்க்கும் பள்ளியைப் பற்றிப் பேசும்.

## ஒரு பள்ளியில் என்ன இருக்கும் {#what-a-school-has}

ஒரு பள்ளியின் பக்கத்தில், வீட்டைப் போலவே, அதன் பெயர், இடம், பகுதிக் குறிப்புகள், உங்கள் இடங்களிலிருந்து தூரம், நீங்கள்
சேமித்த நடைகள், உங்கள் வருகைகள், புகைப்படங்கள் இருக்கும். வாடகை அல்லது விலை, அறைகள்,
குடிபுகுதல் ஆகியவற்றுக்குப் பதிலாக இவை இருக்கும்:

- **கல்வி வாரியம்** (CBSE, ICSE, மாநில வாரியம், IB, Cambridge (IGCSE) அல்லது மற்றவை) மற்றும் **பயிற்று மொழி**;
- **வகுப்புகள்**, **பயண நேரம் (நிமிடங்கள்)** மற்றும் **பள்ளிப் பேருந்து**;
- ஆண்டுக் **கட்டணம்** மற்றும் **சேர்க்கைக் கட்டணம்**;
- பார்க்க வேண்டிய எட்டு விஷயங்களின் **சரிபார்ப்புப் பட்டியல்**, ஒவ்வொன்றுக்கும் 0 முதல் 5 வரை மதிப்பெண்: பாதுகாப்பான இறக்கி-ஏற்றும் இடம், வகுப்பறைகளும் விளையாட்டு மைதானமும், குடிநீரும் கழிப்பறைகளும், அணுகக்கூடிய ஆசிரியர்கள், வகுப்பின் மாணவர் எண்ணிக்கை, ஹோம்வொர்க்கும் தினசரி நேரமும், விளையாட்டும் செயல்பாடுகளும், பாதுகாப்பும் CCTV-யும். இந்தப் பட்டியல் முதல் வரைவு; சொற்கள் மாறலாம்.
- **பள்ளி வருகைகள்**: ஒரு பள்ளி வருகையை அல்லது திறந்த நாளைத் திட்டமிடுங்கள், விரும்பினால் நினைவூட்டலுடன், வரவிருப்பவற்றையும் முடித்தவற்றையும் பாருங்கள்; Android-இல் நினைவூட்டல் தனி அறிவிப்புச் சேனலான **பள்ளி வருகை நினைவூட்டல்கள்**-இல் வரும்;
- **வருகைக்கான கேள்விகள்**: கொண்டுசெல்ல ஆறு கேள்விகள் (கட்டணமும் அதில் அடங்குவனவும், சேர்க்கை எப்படி, வகுப்பின் அளவு, பாதுகாப்பு, தண்ணீரும் கழிப்பறைகளும், வீட்டுப்பாடம், நேரமும் விடுமுறைகளும்), அவற்றை மாற்றலாம், சேர்க்கலாம், மீட்டமைக்கலாம்; பள்ளியின் கேள்விகள் அதற்கே உரியவை, வீடுகளைப் பற்றிக் கேட்கும் கேள்விகளுடன் ஒருபோதும் கலக்காது, முதல் முறை திறக்கும்போதுதான் உங்கள் பட்டியலில் சேரும். இந்தப் பட்டியலும் முதல் வரைவு.

தேடல் இவற்றைக் கொண்டும் பள்ளியைக் கண்டறியும் (வாரியம், "பள்ளிப் பேருந்து", கட்டணம்). படிக்கக்கூடிய நகல்கள் இவற்றைப் பள்ளியின் சொந்தத் தலைப்புகளின் கீழ் காட்டும் (கட்டணம் **கட்டணம்** தலைப்பின் கீழ்), வீட்டு நகலில் *வீடு* என்று இருக்கும் இடத்தில் *பள்ளி* என்று எழுதும், பள்ளிகளின் நகலில் பள்ளிக்கு இல்லாத விலை, மதிப்பெண், BHK, அறைகளை விட்டுவிடும்; காப்புப்பிரதி இவற்றை வைத்திருக்கும். **ஒப்பிடு**, **கேள்**, **திட்டமிடு** நீங்கள் பார்க்கும் பட்டியலிலேயே வேலை செய்யும்: பள்ளிகளைப் பார்க்கும்போது பள்ளிகளை மட்டுமே ஒப்பிடும், அவற்றைப் பற்றி மட்டுமே கேட்கும். பள்ளிகளுக்கு **கேள்**, **திட்டமிடு** உங்கள் சொந்த AI சாவியைக் கேட்கும் (சர்வரின் உதவியாளர் வீடுகளை மட்டுமே படிக்கிறது); **நகலைச் சேமி** நீங்கள் பார்க்கும் பள்ளிகளை மட்டுமே கொண்டிருக்கும், கோப்புப் பெயரில் *schools* இருக்கும்; முழு காப்புப்பிரதியில் அனைத்தும் இருக்கும். Doorprints-க்குப் பகிரும் விளம்பரத்தில் **இதைச் சேமிக்கும் இடம்** இருக்கும், படிப்பதற்கு முன் வீடுகளா பள்ளிகளா என்று தேர்ந்தெடுக்க. மேலுள்ள வடிகட்டு வரிசைகள் (**கல்வி வாரியம்**, **பயிற்று மொழி**, **பள்ளிப் பேருந்து**) பள்ளியின் சொந்தப் பட்டியல்; பள்ளிகளின் நகலில் பள்ளி வருகைகள் **பள்ளி வருகைகள்** என்றும் கேள்விகள் **வருகைக்கான கேள்விகள்** என்றும் பெயரிடப்படும்.

## வடிகட்டு, ஒப்பிடு, நகலெடு {#filter-compare-copy}

வலைத்தளத்தில் பள்ளிகளின் பட்டியலில், நிலை பொத்தான்களுக்குக் கீழே **கல்வி வாரியம்**, **பயிற்று மொழி**, **பள்ளிப் பேருந்து** ஒவ்வொன்றுக்கும் ஒரு வரிசை பொத்தான்கள் இருக்கும். அந்தப் பள்ளிகளை மட்டும் பார்க்க **CBSE** ஐ அழுத்துங்கள்; **ஏதேனும்** வரிசையை முன்பு போல் ஆக்கும். தேர்வுகள் பக்க முகவரியில் இருக்கும்; எனவே புக்மார்க் அல்லது **பின்செல்** அவற்றைத் திரும்பக் கொண்டுவரும். வீடுகளின் பட்டியலில் இந்த வரிசைகள் இல்லை. தொலைபேசியிலும் நிலை சிப்களுக்குக் கீழே இதே வரிசைகள் உள்ளன; பக்க முகவரி இல்லாததால் செயலியை மீண்டும் திறக்கும்போது அவை **ஏதேனும்** என்பதில் தொடங்கும்.

**ஒப்பிடு** ஒவ்வொரு வரிசையிலும் சிறந்த மதிப்பைக் குறிக்கும்; பள்ளிகளுக்குக் குறைந்த பயண நேரமும் குறைந்த கட்டணமும் சிறந்தவை, சரிபார்ப்புப் பட்டியலில் அதிக மதிப்பெண் நல்லது. பள்ளியின் **ஒப்பிடு** எட்டு பட்டியல் விஷயங்கள், கட்டணம், பயண நேரம் ஆகியவற்றை, எல்லாவற்றுக்கும் சம எடையுடன் கணக்கிடும்; சேர்க்கைக் கட்டணம் காட்டப்படும், குறிக்கப்படாது. **அளவுகோல்கள்** (உங்கள் சொந்த எடைகள்) வீடுகளுக்கானவை. **உங்கள் தரவு** பக்கத்தில் நீங்கள் காட்டும் பட்டியல்களுடன் **இதன் நகலைச் சேமிக்கவும்** உள்ளது; அட்டைகளுக்குத் திரும்பாமலே மற்ற பட்டியலின் நகலைச் சேமிக்கலாம். வீடுகளைத் தவிர மற்றவையும் காட்டப்படும்போது, **முழு காப்புப்பிரதி**யும் **காப்புப்பிரதியை இறக்குமதி செய்** என்பதும் எல்லாப் பட்டியல்களையும் கொண்டிருப்பதால் “வீடுகள்” என்பதற்குப் பதிலாக “பதிவுகள்” என்கின்றன.

## மீண்டும் முடக்கவும் {#turn-it-off-again}

**பள்ளிகள் காட்டு** என்பதை முடக்கவும். Doorprints மீண்டும் உங்கள் வீடுகளில்
திறக்கும். எதுவும் நீக்கப்படாது: நீங்கள் சேமித்த பள்ளிகள் இருக்கும், காப்புப்பிரதி அவற்றை வைத்திருக்கும், மீண்டும் காட்டும்போது
அவை திரும்ப வரும்.

அதற்குப் பதிலாக **வீடுகள் காட்டு** என்பதை முடக்கி பள்ளிகளை மட்டும் வைத்திருக்கலாம். உங்கள் வீடுகள் மறைக்கப்படாது, நீக்கப்படாது: ஒரே பட்டியல் காட்டப்படும்போது Doorprints நேராக அதில் திறக்கும்;
அதில் உங்கள் வீடுகள், அவற்றின் **சமீபத்தில் நீக்கப்பட்டவை**, எந்தக் காப்புப்பிரதியும் இருக்கும்; **நீங்கள் கண்காணிப்பவை** என்பதில் **வீடுகள்** எத்தனை சேமிக்கப்பட்டுள்ளன என்ற எண்ணுடன் இன்னும் காணப்படும்.
புதிய பதிவு ஒரு பள்ளியாக இருக்கும். பார்வை நினைவூட்டல் அல்லது பகுதி எழுப்புதலின் *தேடல் பயன்முறையைத் தொடங்கு* பள்ளிகளில் தேடல் பயன்முறையைத் தொடங்கும், ஏனெனில் காட்டப்படும் பட்டியல் பள்ளிகளுடையது. நீங்கள் ஏற்கனவே அமைத்த பார்வை நினைவூட்டல்கள் தொடர்ந்து வரும். **வீடுகள் காட்டு** என்பதை மீண்டும் இயக்கினால் எல்லாம் முன்பு போலவே இருக்கும்.

## காப்புப்பிரதிகள் {#backups}

வீடுகளைத் தவிர மற்றவையும் காட்டப்படும்போது செய்த காப்புப்பிரதி அவற்றைப் பட்டியலிடும் (அதன் `data.json`-இல்
`"search": {"kinds": ["house", "school"], "defaultKind": "house"}`); அதிலுள்ள ஒவ்வொரு பள்ளியும் `"kind": "school"`
என்று சொல்லும். **காப்புப்பிரதியை இறக்குமதி செய்** இதனால் எந்தக் கோப்பையும் மறுக்காது, அதிலுள்ள எதையும் மாற்றாது. தான்
எதைக் கண்காணிக்கிறது என்று ஒருபோதும் தேர்ந்தெடுக்காத உலாவியில் அல்லது தொலைபேசியில் காப்புப்பிரதியின் பட்டியல் பயன்படும்; இல்லையெனில் உங்கள்
தேர்வே இருக்கும். பழைய காப்புப்பிரதிகள் முன்பு போலவே இறக்குமதியாகும்.

## உங்கள் சொந்த சர்வருடன் {#with-your-own-server}

உங்கள் சொந்த சர்வர் வழியாக, சர்வர் அனுமதித்தால் மட்டுமே AI ஒரு பள்ளியின் விளம்பர உரையையும் விவரங்களையும்
பள்ளியினுடையதாகப் படிக்கும். உங்கள் சர்வரில் `.env` கோப்பில் இந்த வரியைச் சேர்க்கவும்
([உங்கள் சொந்த சர்வரை அமைத்தல்](set-up-a-server.md) பார்க்கவும்), பிறகு `docker compose up -d` இயக்கவும்:

```ini
KINDS_AVAILABLE=house,school
```

இது இல்லாமல், சர்வர் சேமித்த ஒவ்வொரு பதிவையும் வீடாகவே படிக்கும்; புதிய பள்ளியில் **விளம்பர உரையிலிருந்து நிரப்பு** ஒரு
பிழையைக் காட்டும். இந்தச் சாதனத்தில் உங்கள் சொந்த AI சாவிக்கு எந்தச் சர்வர் அமைப்பும் தேவையில்லை.

## நீங்கள் சேர்க்கும் வகைகள் (சோதனை) {#kinds-you-add}

*மொழிபெயர்ப்பு மதிப்பாய்வில் உள்ளது.* வீடுகள், பள்ளிகள் தவிர உங்கள் சொந்த வகையையும் வைத்திருக்கலாம், எ.கா. உடற்பயிற்சிக் கூடங்கள், கஃபேக்கள் அல்லது அலுவலகங்கள். இணையதளத்தில் **உங்கள் தரவு** பக்கத்தில், தொலைபேசியில் **அமைப்புகள்** பக்கத்தில், **நீங்கள் கண்காணிப்பவை** கீழ் **நீங்கள் சேர்க்கும் வகைகள் (சோதனை)** என்பதை இயக்கி, **வகைக் கோப்பை இறக்குமதி செய்** என்பதைத் தேர்ந்தெடுக்கவும். வகைக் கோப்பு என்பது வகையின் புலங்களையும் சொற்களையும் சொல்லும் ஒரு சிறிய JSON கோப்பு (அதிகபட்சம் 64 KB). Doorprints முதலில் அதன் பெயர், புலங்கள், சரிபார்ப்புப் பட்டியலைக் காட்டும்; **இந்த வகையைச் சேர்** என்பதைத் தேர்ந்தெடுத்து, அதன் வரிசையில் இயக்கவும். உங்கள் சொற்கள் எல்லா மொழிகளிலும் நீங்கள் எழுதியபடியே தெரியும்.

மிகச் சிறிய பயனுள்ள கோப்பு இப்படி இருக்கும் (முழு வடிவம்: களஞ்சியத்தில் `docs/schemas/kinds/user-kind.schema.json`):

```json
{
  "format": "doorprints-kind/1",
  "id": "u_gym",
  "version": 1,
  "labels": { "new": { "text": "New gym" }, "many": { "text": "Gyms" }, "delete": { "text": "Delete gym" } },
  "statuses": [
    { "id": "NEW", "label": { "text": "New" } },
    { "id": "SHORTLISTED", "label": { "text": "Shortlisted" } },
    { "id": "REJECTED", "label": { "text": "Rejected" } },
    { "id": "TAKEN", "label": { "text": "Joined" } },
    { "id": "NOT_CHOSEN", "label": { "text": "Not chosen" } }
  ],
  "sections": [{ "id": "details", "label": { "text": "Details" } }, { "id": "location", "label": { "text": "Location" } }],
  "core": [
    { "id": "label", "section": "details", "order": 10, "label": { "text": "Gym name" } },
    { "id": "location", "section": "location", "order": 10, "label": { "text": "Location" } }
  ],
  "extras": [{ "id": "hours", "type": "text", "maxLength": 80, "section": "details", "order": 50, "label": { "text": "Opening hours" } }],
  "checklist": [{ "key": "clean", "label": { "text": "Clean and airy" } }],
  "questions": { "seed": "docs/schemas/default-questions.json", "scopes": [{ "id": "BOTH", "cadences": ["month"] }] },
  "search": ["label", "hours"],
  "ai": { "extract": [], "ask": [], "plan": [], "never": [] }
}
```

id `u_` என்று தொடங்கும். மிகப் பெரியது, JSON அல்லாதது, சொல்லில் குறியீடு அல்லது `{`, வரைபடத்தை அமைக்க முயல்வது, AI கேட்பது, அல்லது இல்லாத புலத்தைக் குறிப்பிடுவது: அத்தகைய கோப்பு காரணமும் இடமும் சொல்லி மறுக்கப்படும். அதிலுள்ள எதுவும் இயக்கப்படுவதில்லை. நீங்கள் சேர்க்கும் வகையை எந்த AI-யும் படிக்காது.

முழுக் காப்பு (**நகலைச் சேமி**, பின் காப்பு) உங்கள் வகைகளை எடுத்துச் செல்லும்; வேறு உலாவியில் அல்லது தொலைபேசியில் **காப்பை இறக்குமதி செய்** அவற்றைச் சேர்க்கும். **வகையை நீக்கு** முதலில் கேட்கும், ஒவ்வொரு பதிவையும் வைக்கும். பதிவுகளையும் நீக்க, முதலில் **இந்த இடத்திலுள்ள அனைத்தையும் நீக்கு** என்பதைப் பயன்படுத்தவும். அந்த வகை இல்லாத தொலைபேசி அல்லது உலாவி, நீங்கள் அங்கே வகையை இறக்குமதி செய்யும் வரை அதன் பதிவுகளைத் தன் இயல்புப் பட்டியலில் காட்டும்.
