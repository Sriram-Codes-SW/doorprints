# சிக்கல்களும் அடிக்கடி கேட்கப்படும் கேள்விகளும் {#troubleshooting-and-faq}

**"உங்கள் தரவு வைக்கப்படாமல் போகலாம்."** இணையதளம் உங்கள் வீடுகளை உலாவிக்குள்ளேயே (உலாவிச் சேமிப்பகத்தில்) வைக்கிறது.
இடம் குறையும்போது சில உலாவிகள் ஓர் இணையதளத்தின் தரவை நீக்கலாம். அதைப் பாதுகாக்க:

1. **காப்புப்பிரதியைச் சேமி** தேர்ந்தெடுக்கவும், அல்லது **உங்கள் தரவு** பக்கத்தில் **என் தரவை வைத்திருக்க உலாவியைக் கேள்** தேர்ந்தெடுக்கவும்.
2. இணையதளத்தைச் செயலியாக நிறுவவும். இதுவும் உதவும்.
3. iPhone, iPad-இல், ஒரு தளத்தைச் சிறிது காலம் பயன்படுத்தாவிட்டால் Safari அதன் தரவை நீக்கலாம். Doorprints-ஐ முகப்புத்
   திரையில் சேர்த்து, தொடர்ந்து காப்புப்பிரதியைச் சேமிக்கவும்.

![இணையதளப் பட்டியின் கீழ் சேமிப்பக எச்சரிக்கை: உங்கள் தரவு வைக்கப்படாமல் போகலாம், காப்புப்பிரதியைச் சேமி, இப்போது வேண்டாம் என்பவற்றுடன்](images/web-storage-warning.png)

**வரைபடம் வெறுமையாக அல்லது சாம்பல் நிறமாக உள்ளது.** வரைபடத்துக்கு இணைய இணைப்பு தேவை. உங்கள் வீடுகள் பட்டியலில்
இன்னும் உள்ளன. இணையதளத்தில், ஆஃப்லைனிலும் **என் இருப்பிடத்தில் சேர்** அல்லது **அட்சரேகை, தீர்க்கரேகையைத் தட்டச்சு செய்**
மூலம் வீட்டைச் சேர்க்கலாம்.

**எனக்குக் கேள், திட்டம் அல்லது உதவியாளர் தெரியவில்லை.** AI இயக்கியதும் அவை தோன்றும்:
[உங்கள் சொந்த Gemini சாவியுடன்](settings-and-privacy.md#ai-without-a-server), சர்வர் தேவையில்லை; அல்லது
[உங்கள் சொந்த சர்வர்](set-up-a-server.md) மூலம். சர்வருடன், AI இயக்கியும் அவை தோன்றவில்லை என்றால், அதன்
[சிக்கல் அட்டவணையைப்](set-up-a-server.md#if-something-goes-wrong) பார்க்கவும்.

**API சாவி எங்கே கிடைக்கும்?** API சாவி என்பது ஒரு நீண்ட கடவுச்சொல். உங்கள் சர்வரை அமைக்கும்போது Doorprints API சாவியை
நீங்களே உருவாக்குகிறீர்கள். AI-க்கான Gemini சாவி இலவசம், Google-இடமிருந்து கிடைக்கும்.
[இரண்டு வெவ்வேறு சாவிகள்](set-up-a-server.md#two-different-keys) எது எங்கே போகும் என்று விளக்கும்.

**இரண்டு சாவிகளும் ஒரே நேரத்தில் வேண்டுமா?** இல்லை. Doorprints API சாவி தொடக்கத்திலிருந்தே வேண்டும்: அது இல்லாமல் சர்வர்
இயங்காது. Gemini சாவி AI-க்கு மட்டுமே. அதைப் பின்னர் எப்போது வேண்டுமானாலும் சேர்க்கலாம்
([படி 5](set-up-a-server.md#step-5-write-the-servers-settings-file)).

**என் வீடுகளை இணையதளத்திலிருந்து Android செயலிக்கு மாற்ற முடியுமா?** ஆம். இணையதளத்தில், **முழு காப்புப்பிரதி (ZIP)**
ஆக **ஒரு நகலைச் சேமி**. பிறகு Android-இல் **காப்புப்பிரதியை இறக்குமதி செய்** பயன்படுத்தவும். அல்லது இரண்டையும் ஒரே
சர்வருடன் இணைக்கவும்.

**ஒரே வீட்டை இரண்டு முறை சேர்த்துவிட்டேன்.** கூடுதலானதைத் திறந்து **வீட்டை நீக்கு** என்பதைத் தேர்ந்தெடுக்கவும்.

**Doorprints ஆஃப்லைனில் வேலை செய்யுமா?** ஆம். முதல் முறை திறந்த பிறகு இணையதளம் ஆஃப்லைனில் வேலை செய்யும். Android,
iPhone செயலிகள் எப்போதும் ஆஃப்லைனில் வேலை செய்யும். அடுத்த முறை நீங்கள் இணையத்தில் இருக்கும்போது மாற்றங்கள் உங்கள்
சர்வரைச் சென்றடையும்.

**இந்த உலாவியிலிருந்து அனைத்தையும் நீக்க முடியுமா?** ஆம். **உங்கள் தரவு** பக்கத்தில், **அனைத்துத் தரவையும் நீக்கு**
இந்த உலாவியில் வைத்துள்ள ஒவ்வொரு வீடு, வருகை, படத்தையும் நீக்கும். அவற்றை வைத்திருக்க விரும்பினால் முதலில்
காப்புப்பிரதியைச் சேமிக்கவும்.
