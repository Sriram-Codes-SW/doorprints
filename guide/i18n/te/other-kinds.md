# ఇళ్లతో పాటు పాఠశాలలు {#more-than-houses-experimental}

Doorprints ఇల్లు వెతకడానికి నోట్‌బుక్‌గా మొదలైంది; ఇప్పుడు వెబ్‌సైట్‌లో, ఫోన్‌లలో అదే యాప్ **పాఠశాలలను** కూడా ట్రాక్ చేస్తుంది.
మీరు చూపించేవరకు పాఠశాలలు **ఆఫ్‌లో** ఉంటాయి, కాబట్టి Doorprints ఎప్పటిలాగే మీ ఇళ్లపై తెరుచుకుంటుంది. నిజమైన ఫోన్‌లలో
పాఠశాలలను మేము ఇంకా చేతితో పరీక్షించలేదు; ఏదైనా తప్పుగా కనిపిస్తే మాకు చెప్పండి.

## దీన్ని ఆన్ చేయండి {#turn-it-on}

- **వెబ్‌సైట్:** **మీ డేటా** తెరిచి **మీరు ట్రాక్ చేసేవి** కనుగొనండి. **ఇళ్లు**, **పాఠశాలలు** కోసం ఒక్కో వరుస అక్కడ ఉంటుంది. **పాఠశాలలు చూపించు** ఆన్ చేయండి. వెబ్‌సైట్‌లో ప్రివ్యూ స్విచ్ లేదు.
- **Android మరియు iPhone:** **సెట్టింగ్‌లు** తెరిచి **మీరు ట్రాక్ చేసేవి** కోసం చూడండి. **ఇళ్లు**, **పాఠశాలలు** కోసం ఒక్కో వరుస అక్కడ ఉంటుంది. **పాఠశాలలు చూపించు** ఆన్ చేయండి. ఫోన్‌లలో కూడా ప్రివ్యూ స్విచ్ లేదు.

**డిఫాల్ట్** అంటే Doorprints అడగలేనప్పుడు అనుకునేది: Doorprints‌లోకి మీరు షేర్ చేసే లిస్టింగ్,
లేదా కొత్త నమోదును చేర్చే లింక్. మీరు వేరేది ఎంచుకునేవరకు ఇళ్లే డిఫాల్ట్.

- ఒకటి ఎప్పుడూ ఆన్‌లోనే ఉంటుంది.
- మీ ఎంపిక ఈ బ్రౌజర్‌లో లేదా ఫోన్‌లోనే ఉంటుంది. ఇది సింక్ కాదు, షేర్ కాదు, ఏ కాపీలోనూ చేరదు.

## మీరు ఏమి వెతుకుతున్నారు? {#what-are-you-looking-for}

ఒకటి కంటే ఎక్కువ చూపిస్తున్నప్పుడు, Doorprints **మీరు ఏమి వెతుకుతున్నారు?** తో తెరుచుకుంటుంది: **ఇళ్లు** కోసం ఒక
కార్డ్, **పాఠశాలలు** కోసం ఒక కార్డ్; ప్రతిదానిలో ఎన్ని సేవ్ చేశారో, చివరిసారి ఎప్పుడు మారిందో ఉంటుంది. తెరవడానికి
ఒక కార్డ్‌ను నొక్కండి. అక్కడ ప్రతిదీ ఆ కార్డ్‌దే: జాబితా, మ్యాప్, జాబితా పైన ఉన్న సంఖ్యలు, వెతుకులాట, **పాఠశాల
చేర్చండి** లేదా **ఇల్లు చేర్చండి**, ఖాళీ జాబితా మాటలు. మొదటిసారి, ఇది ఎలా పనిచేస్తుందో ఒక చిన్న గమనిక చెబుతుంది;
**సరే** దాన్ని తీసేస్తుంది.

మారడానికి, మీరు చూస్తున్నదాని పేరుతో పైన ఉన్న బటన్‌ను ఉపయోగించండి (**పాఠశాలలు ▾**): అది మిమ్మల్ని కార్డ్‌లకు
తిరిగి తీసుకువెళ్తుంది. జాబితా నుండి **వెనక్కి** కూడా అంతే.

ఒక్కటే చూపిస్తున్నప్పుడు ఎంచుకోవడానికి ఏమీ ఉండదు: Doorprints ఎప్పటిలాగే నేరుగా అందులోనే తెరుచుకుంటుంది.

ఫోన్‌లో ఈ బటన్ మ్యాప్, జాబితా, పోల్చండి, సెట్టింగ్‌ల పైన ఉంటుంది. **హంట్ మోడ్** ప్రతి విభాగంలో నడుస్తుంది: మ్యాప్‌లోని హంట్ కార్డ్ మీరు ఇళ్లను చూస్తున్నప్పుడూ పాఠశాలలను చూస్తున్నప్పుడూ కనిపిస్తుంది; దాని హెచ్చరికలు, అది నడుస్తున్నప్పుడు కనిపించే నోటిఫికేషన్, పంక్తులు దాన్ని ప్రారంభించిన విభాగాన్ని బట్టి *ఇల్లు* లేదా *పాఠశాల* అని చెబుతాయి (ఇల్లు 30 మీ నుండి, లేదా సెట్టింగ్‌లలో మీరు పెట్టిన దూరం నుండి హెచ్చరిస్తుంది; పాఠశాల 100 మీ నుండి). *మీరు ఏదైనా పాఠశాల దగ్గర ఉన్నారా?* హెచ్చరికను నొక్కితే పాఠశాల తయారవుతుంది. నడక మీరు ప్రారంభించిన విభాగానిది: హంట్ మోడ్ నడుస్తుండగా మరో విభాగానికి వెళ్తే అది ఆగిపోతుంది, Doorprints ఒక పంక్తిలో చెబుతుంది; మ్యాప్ నుండి మళ్లీ ఆన్ చేయండి. **సెట్టింగ్‌లు**లో **బ్రోకర్లు**, **ప్రమాణాలు** ఇళ్ల కోసం; మీరు పాఠశాలలను చూస్తున్నప్పుడు అవి కనిపించవు; **ప్రశ్నలు**, **ఇంటి పరిశీలన** పాఠశాలలకూ కనిపిస్తాయి, పాఠశాల సొంత పదాలతో. వెబ్‌సైట్‌లో **మీ డేటా** **ప్రమాణాలు** కార్డుకు ఇదే చేస్తుంది; దాని **ప్రశ్నలు**, **ఇంటి పరిశీలన** కార్డులు మీరు చూస్తున్న పాఠశాల గురించి మాట్లాడతాయి.

## పాఠశాలలో ఏమి ఉంటాయి {#what-a-school-has}

ఒక పాఠశాల పేజీలో, ఇంటిలాగే, దాని పేరు, చోటు, ప్రాంత గమనికలు, మీ ప్రదేశాల నుండి దూరాలు, మీరు సేవ్ చేసిన నడకలు, మీ
సందర్శనలు, ఫోటోలు ఉంటాయి. అద్దె లేదా ధర, గదులు, ఇంట్లోకి మారడానికి బదులుగా ఇవి
ఉంటాయి:

- **బోర్డు** (CBSE, ICSE, రాష్ట్ర బోర్డు, IB, Cambridge (IGCSE) లేదా ఇతర) మరియు **బోధనా మాధ్యమం**;
- **తరగతులు**, **ప్రయాణ సమయం (నిమిషాలు)** మరియు **స్కూల్ బస్సు**;
- ఏడాదికి **ఫీజు** మరియు **ప్రవేశ ఫీజు**;
- చూడవలసిన ఎనిమిది అంశాల **చెక్‌లిస్ట్**, ప్రతిదానికీ 0 నుండి 5 వరకు మార్కులు: సురక్షితంగా దింపడం, తీసుకెళ్లడం; తరగతి గదులు, ఆటస్థలం; తాగునీరు, మరుగుదొడ్లు; సులభంగా కలవగల ఉపాధ్యాయులు; తరగతిలో విద్యార్థుల సంఖ్య; హోంవర్క్, రోజువారీ సమయపట్టిక; ఆటలు, కార్యకలాపాలు; భద్రత, CCTV. ఈ జాబితా మొదటి ముసాయిదా; పదాలు మారవచ్చు.
- **పాఠశాల సందర్శనలు**: పాఠశాల సందర్శనను లేదా ఓపెన్ డేను ప్లాన్ చేయండి, కావాలంటే రిమైండర్‌తో, రాబోయేవి, పూర్తయినవి చూడండి; Android‌లో రిమైండర్ దాని సొంత నోటిఫికేషన్ ఛానెల్ **పాఠశాల సందర్శన రిమైండర్లు**లో వస్తుంది;
- **సందర్శన కోసం ప్రశ్నలు**: తీసుకెళ్లడానికి ఆరు ప్రశ్నలు (ఫీజు, అందులో ఏమేం ఉన్నాయి, అడ్మిషన్ ఎలా, తరగతి పరిమాణం, భద్రత, నీరు, మరుగుదొడ్లు, హోంవర్క్, సమయాలు, సెలవులు), వాటిని మార్చవచ్చు, జోడించవచ్చు, రీసెట్ చేయవచ్చు; పాఠశాల ప్రశ్నలు దానివే, ఇళ్ల గురించి అడిగే ప్రశ్నలతో ఎప్పుడూ కలవవు, మొదటిసారి తెరిచినప్పుడే మీ జాబితాలో చేరతాయి. ఈ జాబితా కూడా మొదటి ముసాయిదా.

వెతుకులాట వీటితోనూ పాఠశాలను కనుగొంటుంది (బోర్డు, "స్కూల్ బస్సు", ఫీజు). చదవగల కాపీలు వీటిని పాఠశాల సొంత శీర్షికల కింద చూపిస్తాయి (ఫీజు **ఫీజు** కింద), ఇంటి కాపీలో *ఇల్లు* అని ఉన్న చోట *పాఠశాల* అని రాస్తాయి, పాఠశాలల కాపీలో పాఠశాలకు లేని ధర, స్కోరు, BHK, గదులను వదిలేస్తాయి; బ్యాకప్
వీటిని ఉంచుకుంటుంది. **పోల్చండి**, **అడగండి**, **ప్లాన్** మీరు చూస్తున్న జాబితాపైనే పనిచేస్తాయి: పాఠశాలలను చూస్తున్నప్పుడు పాఠశాలలనే పోల్చుతాయి, వాటి గురించే అడుగుతాయి. పాఠశాలలకు **అడగండి**, **ప్లాన్** కోసం మీ సొంత AI కీ కావాలి (సర్వర్ సహాయకుడు ఇళ్లనే చదువుతుంది); **కాపీ సేవ్ చేయండి** మీరు చూస్తున్న పాఠశాలలనే కలిగి ఉంటుంది, ఫైల్ పేరులో *schools* ఉంటుంది; పూర్తి బ్యాకప్‌లో అన్నీ ఉంటాయి. Doorprints కు షేర్ చేసిన లిస్టింగ్‌లో **దీన్ని ఇక్కడ సేవ్ చేయండి** ఉంటుంది, చదివే ముందు ఇళ్లా పాఠశాలలా అని ఎంచుకోవడానికి. పైన ఉన్న ఫిల్టర్ వరుసలు (**బోర్డు**, **బోధనా మాధ్యమం**, **స్కూల్ బస్సు**) పాఠశాల సొంత జాబితా; పాఠశాలల కాపీలో సందర్శనలు **పాఠశాల సందర్శనలు** అని, ప్రశ్నలు **సందర్శన కోసం ప్రశ్నలు** అని పేరు పొందుతాయి.

## ఫిల్టర్, పోల్చడం, కాపీ {#filter-compare-copy}

వెబ్‌సైట్‌లో పాఠశాలల జాబితాలో, స్థితి బటన్ల కింద **బోర్డు**, **బోధనా మాధ్యమం**, **స్కూల్ బస్సు** ప్రతిదానికీ ఒక వరుస బటన్లు ఉంటాయి. ఆ పాఠశాలలను మాత్రమే చూడటానికి **CBSE** నొక్కండి; **ఏదైనా** వరుసను మునుపటిలా చేస్తుంది. ఎంపికలు పేజీ చిరునామాలో ఉంటాయి, కాబట్టి బుక్‌మార్క్ లేదా **వెనుకకు** వాటిని తిరిగి తెస్తాయి. ఇళ్ల జాబితాలో ఇలాంటి వరుసలు ఉండవు. ఫోన్‌లో కూడా స్థితి చిప్స్ కింద ఇవే వరుసలు ఉన్నాయి; పేజీ చిరునామా లేనందున యాప్‌ను మళ్లీ తెరిచినప్పుడు అవి **ఏదైనా**తో మొదలవుతాయి.

**పోల్చండి** ప్రతి వరుసలో ఉత్తమ విలువను గుర్తిస్తుంది; పాఠశాలలకు తక్కువ ప్రయాణ సమయం, తక్కువ ఫీజు ఉత్తమం, చెక్‌లిస్ట్‌లో ఎక్కువ మార్కులు మంచివి. పాఠశాల **పోల్చండి** చెక్‌లిస్ట్‌లోని ఎనిమిది అంశాలను, ఫీజును, ప్రయాణ సమయాన్ని సమానంగా లెక్కిస్తుంది; ప్రవేశ ఫీజు చూపబడుతుంది, గుర్తు పెట్టబడదు. **ప్రమాణాలు** (మీ సొంత బరువులు) ఇళ్ల కోసం. **మీ డేటా**లో మీరు చూపే జాబితాలతో **దీని కాపీని సేవ్ చేయండి** ఉంది, కాబట్టి కార్డులకు తిరిగి వెళ్లకుండానే మరో జాబితా కాపీని సేవ్ చేయవచ్చు. ఇళ్లు కాకుండా ఇతరాలు కూడా చూపుతున్నప్పుడు, **పూర్తి బ్యాకప్**, **బ్యాకప్‌ను దిగుమతి చేయండి** అన్ని జాబితాలనూ కలిగి ఉంటాయి కాబట్టి “ఇళ్లు” బదులు “నమోదులు” అంటాయి.

## మళ్లీ ఆఫ్ చేయండి {#turn-it-off-again}

**పాఠశాలలు చూపించు** ఆఫ్ చేయండి. Doorprints మళ్లీ మీ ఇళ్లపై
తెరుచుకుంటుంది. ఏదీ తొలగించబడదు: మీరు సేవ్ చేసిన పాఠశాలలు ఉంటాయి, బ్యాకప్ వాటిని ఉంచుకుంటుంది, మళ్లీ చూపించినప్పుడు
అవి తిరిగి వస్తాయి.

దానికి బదులు **ఇళ్లు చూపించు** ఆఫ్ చేసి పాఠశాలలను మాత్రమే ఉంచవచ్చు. మీ ఇళ్లు దాచబడవు, తొలగించబడవు: ఒకే జాబితా చూపినప్పుడు Doorprints నేరుగా దానిలోనే తెరుచుకుంటుంది;
దానిలో మీ ఇళ్లు, వాటి **ఇటీవల తొలగించినవి**, ఏ బ్యాకప్ అయినా ఉంటాయి; **మీరు ట్రాక్ చేసేవి**లో **ఇళ్లు** ఎన్ని సేవ్ అయ్యాయో ఆ సంఖ్యతో ఇంకా కనిపిస్తాయి.
కొత్త ఎంట్రీ పాఠశాల అవుతుంది. చూసే రిమైండర్ లేదా ప్రాంతపు మేల్కొలుపులోని *హంట్ మోడ్ ప్రారంభించు* పాఠశాలల్లో హంట్ మోడ్‌ను ప్రారంభిస్తుంది, ఎందుకంటే చూపుతున్న జాబితా పాఠశాలలది. మీరు ఇప్పటికే పెట్టిన చూసే రిమైండర్‌లు ఇంకా వస్తాయి. **ఇళ్లు చూపించు** మళ్లీ ఆన్ చేస్తే అంతా మునుపటిలాగే ఉంటుంది.

## బ్యాకప్‌లు {#backups}

ఇళ్లు కాకుండా ఇంకా చూపిస్తున్నప్పుడు చేసిన బ్యాకప్ వాటిని జాబితా చేస్తుంది (దాని `data.json`‌లో `"search":
{"kinds": ["house", "school"], "defaultKind": "house"}`), అందులోని ప్రతి పాఠశాల `"kind": "school"` అని చెబుతుంది.
**బ్యాకప్ దిగుమతి చేయండి** దీని వల్ల ఏ ఫైల్‌నూ తిరస్కరించదు, అందులో దేన్నీ మార్చదు. తాను ఏమి ట్రాక్ చేస్తుందో ఎప్పుడూ
ఎంచుకోని బ్రౌజర్‌లో లేదా ఫోన్‌లో బ్యాకప్ జాబితా వాడబడుతుంది; లేకపోతే మీ ఎంపికే ఉంటుంది. పాత బ్యాకప్‌లు ఇంతకుముందులాగే దిగుమతి
అవుతాయి.

## మీ సొంత సర్వర్‌తో {#with-your-own-server}

మీ సొంత సర్వర్ ద్వారా, సర్వర్ అనుమతిస్తేనే AI ఒక పాఠశాల లిస్టింగ్ టెక్స్ట్‌ను, వివరాలను పాఠశాలవిగా చదువుతుంది. మీ
సర్వర్‌లో `.env` ఫైల్‌కు ఈ లైన్ జోడించండి ([మీ సొంత సర్వర్‌ను ఏర్పాటు చేయండి](set-up-a-server.md) చూడండి), తర్వాత
`docker compose up -d` నడపండి:

```ini
KINDS_AVAILABLE=house,school
```

ఇది లేకుంటే, సర్వర్ సేవ్ చేసిన ప్రతి నమోదునూ ఇల్లుగానే చదువుతుంది, కొత్త పాఠశాలపై **లిస్టింగ్ టెక్స్ట్ నుండి నింపండి**
ఒక లోపాన్ని చూపిస్తుంది. ఈ పరికరంలో మీ సొంత AI కీకి ఏ సర్వర్ సెట్టింగ్ అవసరం లేదు.

## మీరు జోడించే రకాలు (వెబ్‌సైట్, ప్రయోగాత్మకం) {#kinds-you-add}

*అనువాదం సమీక్షలో ఉంది.* ఇళ్లు, పాఠశాలలతో పాటు మీ సొంత రకాన్నీ ఉంచుకోవచ్చు, ఉదా. జిమ్‌లు, కేఫ్‌లు లేదా ఆఫీసులు. **మీ డేటా**లో **మీరు ట్రాక్ చేసేవి** కింద **మీరు జోడించే రకాలు (ప్రయోగాత్మకం)** ఆన్ చేసి, **రకం ఫైల్‌ను ఇంపోర్ట్ చేయండి** ఎంచుకోండి. రకం ఫైల్ అనేది రకం యొక్క ఫీల్డ్‌లు, పదాలను చెప్పే చిన్న JSON ఫైల్ (గరిష్ఠంగా 64 KB). Doorprints ముందుగా దాని పేరు, ఫీల్డ్‌లు, చెక్‌లిస్ట్ చూపుతుంది; **ఈ రకాన్ని జోడించండి** ఎంచుకుని, దాని వరుసలో ఆన్ చేయండి. మీ పదాలు అన్ని భాషల్లో మీరు రాసినట్లే కనిపిస్తాయి.

అతి చిన్న ఉపయోగకరమైన ఫైల్ ఇలా ఉంటుంది (పూర్తి ఫార్మాట్: రిపోజిటరీలో `docs/schemas/kinds/user-kind.schema.json`):

```json
{
  "format": "doorprints-kind/1",
  "id": "u_gym",
  "version": 1,
  "labels": { "new": { "text": "New gym" }, "many": { "text": "Gyms" }, "delete": { "text": "Delete gym" } },
  "statuses": [
    { "id": "NEW", "label": { "text": "New" } },
    { "id": "SHORTLISTED", "label": { "text": "Shortlisted" } },
    { "id": "REJECTED", "label": { "text": "Rejected" } },
    { "id": "TAKEN", "label": { "text": "Joined" } },
    { "id": "NOT_CHOSEN", "label": { "text": "Not chosen" } }
  ],
  "sections": [{ "id": "details", "label": { "text": "Details" } }, { "id": "location", "label": { "text": "Location" } }],
  "core": [
    { "id": "label", "section": "details", "order": 10, "label": { "text": "Gym name" } },
    { "id": "location", "section": "location", "order": 10, "label": { "text": "Location" } }
  ],
  "extras": [{ "id": "hours", "type": "text", "maxLength": 80, "section": "details", "order": 50, "label": { "text": "Opening hours" } }],
  "checklist": [{ "key": "clean", "label": { "text": "Clean and airy" } }],
  "questions": { "seed": "docs/schemas/default-questions.json", "scopes": [{ "id": "BOTH", "cadences": ["month"] }] },
  "search": ["label", "hours"],
  "ai": { "extract": [], "ask": [], "plan": [], "never": [] }
}
```

id `u_` తో మొదలవుతుంది. చాలా పెద్దది, JSON కానిది, పదంలో మార్కప్ లేదా `{`, మ్యాప్‌ను అమర్చే ప్రయత్నం, AI అడగడం, లేదా లేని ఫీల్డ్‌ను పేర్కొనడం: అలాంటి ఫైల్ కారణం, చోటుతో తిరస్కరించబడుతుంది. అందులోని ఏదీ నడపబడదు. మీరు జోడించే రకాన్ని ఏ AI చదవదు.

పూర్తి బ్యాకప్ (**కాపీని సేవ్ చేయండి**, తర్వాత బ్యాకప్) మీ రకాలను తీసుకెళ్తుంది; మరో బ్రౌజర్‌లో **బ్యాకప్‌ను ఇంపోర్ట్ చేయండి** వాటిని జోడిస్తుంది. **రకాన్ని తీసివేయండి** ముందుగా అడుగుతుంది, ప్రతి నమోదునూ ఉంచుతుంది. నమోదులనూ తొలగించాలంటే ముందుగా **ఈ స్పేస్‌లోని అన్నీ తొలగించు** వాడండి. ఫోన్ యాప్‌లు తర్వాత వస్తాయి.
