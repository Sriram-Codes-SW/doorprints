Sign in

With Docker: run docker compose logs api and look for "Doorprints owner page". If no browser is signed in, restart the server for a new link; otherwise choose "Add another browser" in a signed-in browser.

Scan it with the phone's camera: the Doorprints app opens and connects. It works once, within 10 minutes, so show it only to your own device.

AI (Google Gemini)

AI is not set up on this server. To use it, set APP_AI_ENABLED=true in the server's settings file and restart the server.

This server uses Google Cloud Vertex AI, which needs no Gemini key.

Make a separate key just for Doorprints in Google AI Studio, so you can delete it there at any time. The key is stored encrypted and cannot be shown again. Open Google AI Studio

Devices

Each device has its own key. AI requests use your Gemini key, so AI is off for a new device until you turn it on here.
